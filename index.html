Spearhead Artillery Calculator i
Coordinate Input Guide:

XY Grid (3-digits): 050 080
Value can be read from under the cursor on the map. Snaps to center if the grid by default, can be finetuned by numpad values.

XY Direct (4+ digits): 05000 08000
Value can be read from GPS on the map or by using laser with SAL drone.

Elevation (E): 050 080 120
Can be read from under the cursor on the map or GPS

Numpad finetuning: 050 080 120 94 (Numpad 94)
Use numpad grid subdivision to fine-tune the position within the grid (can be used as many times as you like)
